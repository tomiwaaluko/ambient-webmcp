WebMCP required

This demo needs Google Chrome with the WebMCP origin trial active for https://ambient-host-tomiwaalukos-projects.vercel.app. Without document.modelContext, federated tools cannot register and this page cannot demonstrate adoption.

No install step and no browser flag — the origin trial token in this document supplies trial access when Chrome accepts it.
